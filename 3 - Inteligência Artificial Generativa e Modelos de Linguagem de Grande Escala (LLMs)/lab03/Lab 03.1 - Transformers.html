Ex 1: Trabalhar com o modelo BERT Base

Tarefa

Explorar o modelo BERT Base para analisar uma frase. ### Instruções 1. Carrega o modelo e o tokenizador utilizando a biblioteca transformers. 2. Define uma mova frase de entrada (podes usar uma frase filosófica ou inventar). 3. Gera a saída do modelo e interpreta as dimensões resultantes.

Código base: Usa o ficheiro ex_01_modelo_BERT_BASE.py.

Ex 2: Implementar Classificação de Imagens

Tarefa

Classificar imagens utilizando um pipeline de classificação de imagens. ### Instruções 1. Utiliza o pipeline image-classification da biblioteca transformers. 2. Classifica uma imagem local (prado.jpg).

Código base: Usa o ficheiro ex_02_pipeline1_visao.py.

Adiciona ao exercício

  1. Substitui a imagem utilizada por uma diferente (por exemplo, uma foto de um animal) e observa os resultados.

Ex 3: Construir um Pipeline de Análise de Sentimentos

Tarefa

Criar um pipeline para analisar sentimentos em textos. ### Instruções 1. Configura o pipeline text-classification. 2. Testa com frases em inglês para identificar sentimentos.

Código base: Usa o ficheiro ex_03_pipeline2_analise_sentimentos.py.

Adiciona ao exercício

  1. Adapta o pipeline para analisar sentimentos utilizando frases positivas e negativas.

Ex 4: Explorar a Transcrição de Áudio

Tarefa

Utilizar o modelo Whisper para transcrever áudio. ### Instruções 1. Configura o pipeline de transcrição com o modelo openai/whisper-base. 2. Transcreve o ficheiro áudio 1.flac.

Código base: Usa o ficheiro ex_04_pipeline3_audio.py.

Adiciona ao exercício

  1. Substitui o ficheiro de áudio por outro e analisa a transcrição.

Ex 5: Gerar Música com o Modelo MusicGen

Tarefa

Explorar geração de música baseada em texto. ### Instruções 1. Analisa o pipeline text-to-audio com o modelo facebook/musicgen-small. 2. Define um prompt criativo para a geração musical.

Código base: Usa o ficheiro ex_05_pipeline4_generate_music.py.

Adiciona ao exercício

  1. Altera o prompt para outro estilo musical e analisa os resultados.
  2. Partilha o ficheiro gerado com os colegas para feedback.
