Ex 06: Operações Aritméticas, Máscaras e Blending de Imagens no OpenCV

Descrição

Neste exercício, vamos:

  1. Demonstrar a diferença entre a soma saturada do OpenCV e a soma modular do NumPy.
  2. Sobrepor uma imagem de um robô (bot.png) sobre uma imagem de fundo (Ovar.jpg) através da criação de máscaras.
  3. Combinar a imagem resultante com uma terceira imagem de fundo (bot_background.png) utilizando a função cv2.addWeighted, ajustando o tamanho da imagem para evitar erros de dimensão.

Passo 1: Criação do Arquivo Python

Crie um arquivo chamado ex_06_Operacoes_e_Mascaras_no_OpenCV.py e insira o código abaixo.

Passo 2: Importar as Bibliotecas

import cv2
import numpy as np

Passo 3: Operações Aritméticas com Arrays

Demonstraremos a diferença entre cv2.add() e a soma simples do NumPy em arrays uint8.

x = np.uint8([[250]])
y = np.uint8([[10]])

print("Soma com cv2.add:", cv2.add(x, y))  # Soma saturada (250 + 10 = 260 => 255)
print("Soma com NumPy  :", x + y)         # Soma modular (250 + 10 = 260 % 256 = 4)

A saída esperada no terminal:

Soma com cv2.add: [[255]]
Soma com NumPy  : [4]

Passo 4: Carregar e Preparar Imagens

Carregue a imagem de fundo Ovar.jpg e a imagem do robô bot.png.

img1 = cv2.imread('Ovar.jpg')
img2 = cv2.imread('bot.png')

Verifique se as imagens foram carregadas corretamente:

if img1 is None:
    raise IOError("Erro ao carregar 'Ovar.jpg'. Verifique o nome e a localização do arquivo.")
if img2 is None:
    raise IOError("Erro ao carregar 'bot.png'. Verifique o nome e a localização do arquivo.")

Passo 5: Criar Máscaras e Sobrepor o Robô sobre a Imagem de Fundo

Defina a região de interesse (ROI) na imagem img1 onde o robô img2 será inserido.

rows, cols, channels = img2.shape
roi = img1[0:rows, 0:cols]

Converta a imagem do robô para escala de cinza e crie uma máscara binária.

img2gray = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)
ret, mask = cv2.threshold(img2gray, 10, 255, cv2.THRESH_BINARY)
mask_inv = cv2.bitwise_not(mask)

Remova a área do robô da ROI do fundo:

img1_bg = cv2.bitwise_and(roi, roi, mask=mask_inv)

Obtenha apenas a parte do robô:

img2_fg = cv2.bitwise_and(img2, img2, mask=mask)

Combine as duas partes e atualize a imagem principal img1:

dst = cv2.add(img1_bg, img2_fg)
img1[0:rows, 0:cols] = dst

Passo 6: Leitura da Terceira Imagem e Blending

Carregue a terceira imagem (bot_background.png):

img3 = cv2.imread('bot_background.png')
if img3 is None:
    raise IOError("Erro ao carregar 'bot_background.png'. Verifique o nome e a localização do arquivo.")

Garanta que img3 tenha o mesmo tamanho que img1 para evitar erros na função cv2.addWeighted:

img3 = cv2.resize(img3, (img1.shape[1], img1.shape[0]))

Agora realize o blending entre img1 (que já possui o robô sobreposto) e img3:

final = cv2.addWeighted(img1, 0.7, img3, 0.3, 0)

Passo 7: Exibir as Imagens

Exiba as imagens para verificar os resultados:

cv2.imshow('Imagem com Robo', img1)
cv2.imshow('Imagem de Fundo Extra', img3)
cv2.imshow('Resultado Blending', final)
cv2.waitKey(0)
cv2.destroyAllWindows()

Passo 8: Executar o Programa

No terminal, execute:

python ex_06_Operacoes_e_Mascaras_no_OpenCV.py

Resultado Esperado

  • No terminal, você verá a diferença entre a soma saturada do OpenCV e a soma modular do NumPy.
  • Na janela “Imagem com Robo”, o robô bot.png deve aparecer sobre a imagem Ovar.jpg.
  • Na janela “Resultado Blending”, você verá a combinação da imagem resultante com bot_background.png, criando um efeito de mistura entre as duas imagens.

Feche as janelas pressionando qualquer tecla.

Ex 07: Transformações Geométricas no OpenCV

Descrição

Neste exercício, serão realizadas diversas transformações geométricas sobre uma imagem:

  1. Escalamento (Scaling) com cv2.resize() para aumentar e reduzir.
  2. PyrDown e PyrUp: Redução e ampliação utilizando pirâmides Gaussianas.
  3. Translação (Translation) usando cv2.warpAffine() com matriz de translação.
  4. Rotação (Rotation) usando cv2.getRotationMatrix2D() e cv2.warpAffine().
  5. Transformação Afim (Affine Transformation) usando cv2.getAffineTransform() e cv2.warpAffine().
  6. Transformação por Perspectiva (Perspective Transformation) usando cv2.getPerspectiveTransform() e cv2.warpPerspective().

Passo 1: Criação do Arquivo Python

Crie o ficheiro ex_07_Transformacoes_Geometricas_no_OpenCV.py e insira o código abaixo.

Passo 2: Importar as Bibliotecas

import cv2
import numpy as np

Passo 3: Carregar a Imagem

Certifique-se de ter a imagem Ovar.jpg no mesmo diretório do script.

img = cv2.imread('Ovar.jpg')
if img is None:
    raise IOError("Erro ao carregar 'Ovar.jpg'. Verifique o nome e a localização do arquivo.")

height, width = img.shape[:2]

Passo 4: Escalamento (Resize)

  • Aumentar a imagem (2x)
  • Reduzir a imagem (0.5x)
img_scale_up = cv2.resize(img, None, fx=2, fy=2, interpolation=cv2.INTER_CUBIC)
img_scale_down = cv2.resize(img, None, fx=0.5, fy=0.5, interpolation=cv2.INTER_AREA)

Passo 5: PyrDown e PyrUp

  • cv2.pyrDown() reduz o tamanho da imagem pela metade (tanto em largura quanto em altura).
  • cv2.pyrUp() aumenta o tamanho da imagem em duas vezes (inverso do pyrDown).
img_pyr_down = cv2.pyrDown(img)   # Reduz a imagem
img_pyr_up = cv2.pyrUp(img)       # Aumenta a imagem

Passo 6: Translação (Translation)

Criação de uma matriz de translação para deslocar a imagem.

tx, ty = 100, 50  # Deslocar 100 pixeis à direita e 50 pixeis para baixo
M_translation = np.float32([[1, 0, tx],
                            [0, 1, ty]])
img_translation = cv2.warpAffine(img, M_translation, (width, height))

Passo 7: Rotação (Rotation)

Rodar a imagem em torno do centro.

center = (width//2, height//2)  
angle = 45                      
scale = 1.0                     

M_rotation = cv2.getRotationMatrix2D(center, angle, scale)
img_rotation = cv2.warpAffine(img, M_rotation, (width, height))

Passo 8: Transformação Afim (Affine Transform)

Definir três pontos de origem e três pontos de destino para criar uma transformação linear.

pts1 = np.float32([[50, 50],
                   [200, 50],
                   [50, 200]])

pts2 = np.float32([[10, 100],
                   [200, 50],
                   [100, 250]])

M_affine = cv2.getAffineTransform(pts1, pts2)
img_affine = cv2.warpAffine(img, M_affine, (width, height))

Passo 9: Transformação por Perspectiva (Perspective Transform)

Definir quatro pontos de origem e quatro pontos de destino para alterar a perspectiva.

pts1_persp = np.float32([[50,50],
                         [width-50,50],
                         [50,height-50],
                         [width-50,height-50]])

pts2_persp = np.float32([[0,0],
                         [300,0],
                         [0,300],
                         [300,300]])

M_perspective = cv2.getPerspectiveTransform(pts1_persp, pts2_persp)
img_perspective = cv2.warpPerspective(img, M_perspective, (300, 300))

Passo 10: Exibir as Imagens

cv2.imshow('Original', img)
cv2.imshow('Scale Up (2x)', img_scale_up)
cv2.imshow('Scale Down (0.5x)', img_scale_down)
cv2.imshow('PyrDown', img_pyr_down)
cv2.imshow('PyrUp', img_pyr_up)
cv2.imshow('Translation', img_translation)
cv2.imshow('Rotation 45 graus', img_rotation)
cv2.imshow('Affine Transformation', img_affine)
cv2.imshow('Perspective Transformation', img_perspective)

cv2.waitKey(0)
cv2.destroyAllWindows()

Passo 11: Executar o Programa

No terminal:

python ex_07_Transformacoes_Geometricas_no_OpenCV.py

Resultado Esperado

  • Original: Imagem sem modificações.
  • Scale Up (2x): Imagem ampliada em 2 vezes.
  • Scale Down (0.5x): Imagem reduzida pela metade.
  • PyrDown: Imagem reduzida usando pirâmides Gaussianas.
  • PyrUp: Imagem ampliada usando pirâmides Gaussianas.
  • Translation: Imagem deslocada à direita e para baixo.
  • Rotation 45 graus: Imagem rotacionada em 45 graus.
  • Affine Transformation: Imagem transformada afim (cisalhamento, rotação e/ou translação baseada em três pontos).
  • Perspective Transformation: Imagem alterada de perspectiva (quatro pontos).

Feche todas as janelas pressionando qualquer tecla.

Ex 08: Carregamento e Correção de Cores (BGR para RGB e HSV)

Descrição

  1. Carregar Imagem com OpenCV: Carregar a imagem Ovar.jpg usando cv2.imread().
  2. Exibir com Matplotlib sem Correção: Exibir a imagem usando matplotlib.pyplot.imshow() diretamente após o carregamento. Será observado que as cores não aparecem corretamente.
  3. Corrigir a Ordem dos Canais (BGR para RGB): Converter a imagem de BGR para RGB usando cv2.cvtColor(img, cv2.COLOR_BGR2RGB) e exibi-la novamente, observando a diferença.
  4. Converter para HSV: Converter a imagem de BGR para HSV usando cv2.COLOR_BGR2HSV e exibir o resultado no Matplotlib.

Passo 1: Criação do Arquivo Python

Crie o arquivo ex_08_Correcao_de_Espaço_de_Cores.py e adicione o código abaixo.

Passo 2: Importar as Bibliotecas

import cv2
import matplotlib.pyplot as plt

Passo 3: Carregar a Imagem com OpenCV

Certifique-se de ter a imagem Ovar.jpg no mesmo diretório do script.

img = cv2.imread('Ovar.jpg')
if img is None:
    raise IOError("Erro ao carregar 'Ovar.jpg'. Verifique o nome e a localização do arquivo.")

Note que img está no formato BGR.

Passo 4: Exibir a Imagem Diretamente no Matplotlib

O Matplotlib espera imagens no formato RGB. Se exibirmos a imagem diretamente, as cores ficarão distorcidas.

plt.figure(figsize=(10,4))

plt.subplot(1,3,1)
plt.imshow(img)  # Aqui as cores aparecerão incorretas (BGR exibido como RGB)
plt.title('BGR exibido diretamente')
plt.axis('off')

Passo 5: Converter de BGR para RGB

Converter a imagem para RGB para exibir corretamente no Matplotlib:

img_rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)

plt.subplot(1,3,2)
plt.imshow(img_rgb)
plt.title('Imagem em RGB')
plt.axis('off')

Agora a imagem deve aparecer com as cores corretas.

Passo 6: Converter de BGR para HSV

Converter a imagem para o espaço de cor HSV:

img_hsv = cv2.cvtColor(img, cv2.COLOR_BGR2HSV)

Por padrão, imshow do Matplotlib irá interpretar o array HSV também como RGB. Para visualizar de maneira coerente, não existe uma conversão direta para exibir HSV “corretamente” no plt.imshow(), pois HSV é um espaço de cor conceptual, não diretamente representável como uma imagem colorida normal. Ainda assim, podemos exibir a imagem HSV diretamente e notar que a aparência é diferente da RGB.
Observação: O que veremos será a interpretação dos valores HSV como se fossem RGB, o que não faz sentido sem conversão. É apenas para fins de ilustrar o resultado num espaço diferente. Idealmente, para analisar HSV, deveríamos inspecionar cada canal separadamente ou converter de volta a RGB antes de exibir. Entretanto, aqui, exibiremos diretamente para perceber o quão “estranho” fica.

plt.subplot(1,3,3)
plt.imshow(img_hsv)
plt.title('Imagem em HSV (interpretada como RGB)')
plt.axis('off')

Para ver os canais separadamente, poderíamos fazer algo como:

# Separar canais H, S e V para visualizar
h, s, v = cv2.split(img_hsv)

# Exibir o canal H, S e V separadamente em tons de cinza
plt.figure(figsize=(10,3))
plt.subplot(1,3,1)
plt.imshow(h, cmap='gray')
plt.title('Canal H')

plt.subplot(1,3,2)
plt.imshow(s, cmap='gray')
plt.title('Canal S')

plt.subplot(1,3,3)
plt.imshow(v, cmap='gray')
plt.title('Canal V')

Passo 7: Mostrar as Janelas do Matplotlib

plt.tight_layout()
plt.show()

Executar o Programa

No terminal, execute:

python ex_08_Correcao_de_Espaço_de_Cores.py

Resultado Esperado

  • Primeira Imagem (BGR exibido diretamente): Cores distorcidas, pois a imagem está em BGR e o Matplotlib interpreta como RGB.
  • Segunda Imagem (RGB): Cores corretas, após converter de BGR para RGB.
  • Terceira Imagem (HSV): A imagem apresentada de forma estranha, pois o HSV não é um espaço diretamente interpretado como RGB. Esta é apenas uma ilustração.
  • As figuras com canais H, S, V em tons de cinza permitirão compreender a decomposição da imagem em HSV.

Passo 2: Importar Bibliotecas

  3. Centralizar o espectro, de modo a posicionar as frequências baixas no centro da imagem.
  4. Exibir o espectro de magnitude da imagem transformada.
  5. Aplicar a Transformada Inversa de Fourier Discreta (cv2.idft()) para retornar ao domínio espacial e obter a imagem original novamente.

Passo 1: Criar o Arquivo Python

Crie o arquivo ex_13_Analise_DFT_IDFT.py e insira o código abaixo.

import numpy as np

A função cv2.dft() espera uma matriz do tipo float32. Também é comum “acolchoar” a imagem para obter dimensões ótimas para a DFT, porém neste exemplo simples faremos apenas a conversão de tipo.

A DFT no OpenCV coloca as frequências baixas no canto da imagem. Para melhor visualização, é comum deslocar o zero da transformada para o centro da imagem. Podemos fazer isso com a função np.fft.fftshift().

dft_shift = np.fft.fftshift(dft)

Passo 7: Calcular o Espectro de Magnitude

O espectro de magnitude é dado por log(1 + sqrt(real^2 + imag^2)).

magnitude_spectrum = 20 * np.log(cv2.magnitude(dft_shift[:,:,0], dft_shift[:,:,1]) + 1)
magnitude_spectrum = np.uint8(cv2.normalize(magnitude_spectrum, None, 0, 255, cv2.NORM_MINMAX))

cv2.destroyAllWindows()

Passo 9: Aplicar a IDFT para Reconstruir a Imagem

Para retornar ao domínio espacial, aplicamos a IDFT. Antes disso, precisamos desfazer o shift aplicado ao espectro.

# Desfazer o shift:
dft_ishift = np.fft.ifftshift(dft_shift)

# Aplicar IDFT:

img_back = cv2.magnitude(img_back[:,:,0], img_back[:,:,1])

Normalizar a imagem resultante para poder exibi-la adequadamente:

img_back_normalized = cv2.normalize(img_back, None, 0, 255, cv2.NORM_MINMAX)

  3. Detecção de Círculos com Hough Circles:
    Identificar círculos presentes na imagem por meio da Transformada de Hough para círculos.

Passo 1: Criar o Arquivo Python

Crie o arquivo ex_16_Watershed_Hough.py e insira o código abaixo.

Passo 2: Importar Bibliotecas

import cv2
import numpy as np

Passo 3: Carregar a Imagem

img = cv2.imread('bot.png')
if img is None:
    raise IOError("Erro ao carregar 'bot.png'. Verifique o nome e a localização do arquivo.")

Segmentação por Watershed

A segmentação por Watershed necessita de uma imagem em tons de cinza, binarizações e marcadores.

Passos para Watershed:

  1. Converter a imagem para tons de cinza.
  2. Aplicar limiarização (threshold) ou binarização para encontrar áreas de primeiro plano e fundo.
  3. Encontrar marcadores usando distância transform e connected components.
  4. Aplicar o algoritmo Watershed.
# Converter para tons de cinza
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# Aplicar um limiar (poderíamos usar Otsu ou um threshold fixo)
ret, thresh = cv2.threshold(gray, 0, 255, cv2.THRESH_BINARY_INV+cv2.THRESH_OTSU)

# Remover ruídos pequenos com abertura morfológica
kernel = np.ones((3,3), np.uint8)
opening = cv2.morphologyEx(thresh, cv2.MORPH_OPEN, kernel, iterations=2)

# Dilatação para obter sure background
sure_bg = cv2.dilate(opening, kernel, iterations=3)

# Distance transform para encontrar sure foreground
dist_transform = cv2.distanceTransform(opening, cv2.DIST_L2, 5)
ret, sure_fg = cv2.threshold(dist_transform, 0.7*dist_transform.max(), 255, 0)

# Sure_fg deve ser uint8
sure_fg = np.uint8(sure_fg)
unknown = cv2.subtract(sure_bg, sure_fg)

# Marcadores: cada componente conectado do foreground é um marcador
ret, markers = cv2.connectedComponents(sure_fg)

# Somar 1 a todos os marcadores, para background ser 1 ao invés de 0
markers = markers + 1

# Marcar os pixels desconhecidos como 0
markers[unknown == 255] = 0

# Aplicar Watershed
markers = cv2.watershed(img, markers)
watershed_result = img.copy()
watershed_result[markers == -1] = [0, 0, 255]  # Bordas marcadas em vermelho

Detecção de Linhas (Hough Lines)

Para detectar linhas, normalmente aplicamos Canny primeiro e depois a transformada de Hough:

gray_for_lines = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
edges = cv2.Canny(gray_for_lines, 50, 150, apertureSize=3)

lines = cv2.HoughLinesP(edges, 1, np.pi/180, 100, minLineLength=100, maxLineGap=10)
hough_lines_result = img.copy()

if lines is not None:
    for line in lines:
        x1, y1, x2, y2 = line[0]
        cv2.line(hough_lines_result, (x1,y1), (x2,y2), (0,255,0), 2)

Detecção de Círculos (Hough Circles)

Para detectar círculos, aplicamos a função cv2.HoughCircles() sobre a imagem em tons de cinza suavizada:

gray_for_circles = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
gray_for_circles = cv2.medianBlur(gray_for_circles, 5)

circles = cv2.HoughCircles(gray_for_circles, cv2.HOUGH_GRADIENT, dp=1, minDist=50,
                           param1=100, param2=30, minRadius=0, maxRadius=0)
hough_circles_result = img.copy()

if circles is not None:
    circles = np.uint16(np.around(circles))
    for i in circles[0,:]:
        # Desenhar círculo
        cv2.circle(hough_circles_result, (i[0], i[1]), i[2], (255,0,0), 2)
        # Desenhar centro
        cv2.circle(hough_circles_result, (i[0], i[1]), 2, (0,0,255), 3)

Exibir Resultados com cv2.imshow()

cv2.imshow('Original', img)
cv2.imshow('Watershed Result', watershed_result)
cv2.imshow('Hough Lines', hough_lines_result)
cv2.imshow('Hough Circles', hough_circles_result)

cv2.waitKey(0)
cv2.destroyAllWindows()

Ex 17: Detecção de Objetos com Template Matching

Descrição

Este exercício consiste em:

  1. Carregar uma imagem em que há várias moedas de euro (coins_euros.jpg).
  2. Converter a imagem para tons de cinza.
  3. Carregar uma imagem de uma moeda de 20 centavos (coin_20cents.jpg), que servirá como template.
  4. Aplicar o template matching para encontrar regiões na imagem original que sejam semelhantes ao template.
  5. Desenhar retângulos em torno dos locais detectados.
  6. Salvar a imagem resultante com as detecções.

Passo 1: Criação do Arquivo Python

Crie o arquivo ex_17_Template_Matching.py e insira o código abaixo.

Passo 2: Importar Bibliotecas

import cv2
import numpy as np
from matplotlib import pyplot as plt

Passo 3: Carregar a Imagem Original

Carregue a imagem coins_euros.jpg. Certifique-se de que o arquivo esteja no mesmo diretório do script:

img_rgb = cv2.imread('coins_euros.jpg')
if img_rgb is None:
    raise IOError("Erro ao carregar 'coins_euros.jpg'. Verifique o nome e a localização do arquivo.")

Converta a imagem para tons de cinza, pois o template matching é frequentemente aplicado em imagens em escala de cinza.

img_gray = cv2.cvtColor(img_rgb, cv2.COLOR_BGR2GRAY)

Passo 4: Carregar o Template

Carregue a imagem do template, por exemplo, uma moeda de 20 centavos (coin_20cents.jpg):

template = cv2.imread('coin_20cents.jpg', 0)
if template is None:
    raise IOError("Erro ao carregar 'coin_20cents.jpg'. Verifique o nome e a localização do arquivo.")

Obtenha as dimensões do template para poder desenhar o retângulo depois:

w, h = template.shape[::-1]

Passo 5: Aplicar o Template Matching

Utilize o método cv2.TM_CCOEFF_NORMED para detectar regiões semelhantes ao template. Ajuste o threshold conforme necessário (0.8 é um bom ponto de partida):

res = cv2.matchTemplate(img_gray, template, cv2.TM_CCOEFF_NORMED)
threshold = 0.8
loc = np.where(res >= threshold)

Passo 6: Desenhar os Retângulos ao Redor das Detecções

Para cada ponto onde o template foi encontrado, desenhe um retângulo vermelho sobre a imagem original.

for pt in zip(*loc[::-1]):
    cv2.rectangle(img_rgb, pt, (pt[0] + w, pt[1] + h), (0,0,255), 2)

Passo 7: Salvar a Imagem Resultante

Salve a imagem com as detecções para inspeção posterior.

cv2.imwrite('res_euros.jpg', img_rgb)

Também é possível exibir a imagem resultante em uma janela do OpenCV:

cv2.imshow('Detecções', img_rgb)
cv2.waitKey(0)
cv2.destroyAllWindows()

Passo 8: Executar o Programa

No terminal, execute:

python ex_17_Template_Matching.py

Resultado Esperado

  • Uma imagem chamada res_euros.jpg será gerada, mostrando retângulos vermelhos em torno das moedas de 20 centavos detectadas.
  • Ao abrir a janela “Detecções” do OpenCV, também será possível visualizar diretamente o resultado na tela.
  • Caso nenhuma correspondência seja encontrada, tente ajustar o valor do threshold para torná-lo mais permissivo ou mais restritivo.
