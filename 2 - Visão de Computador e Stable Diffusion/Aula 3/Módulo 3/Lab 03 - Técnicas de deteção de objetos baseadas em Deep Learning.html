Ex 01: Deteção de Objetos 3D (Ex: Chávena) em Tempo Real com MediaPipe Objectron

Descrição

Neste exercício, vamos utilizar a biblioteca MediaPipe Objectron para detetar e acompanhar objetos 3D específicos (neste caso, uma chávena) em tempo real a partir da webcam. O Objectron é capaz de fornecer a pose do objeto (rotação e translação) e as suas landmarks 2D, permitindo a visualização de um modelo 3D projetado na imagem.

Etapas principais:

  1. Capturar vídeo em tempo real a partir da webcam.
  2. Utilizar o MediaPipe Objectron para detetar objetos do tipo chávena (cup).
  3. Desenhar as landmarks 2D do objeto e o respetivo eixo 3D na imagem.
  4. Exibir o resultado numa janela, com a imagem espelhada horizontalmente, para um estilo “selfie”.
  5. Permitir ao utilizador encerrar a execução premindo a tecla ESC.

Pré-Requisitos

  • Python 3.12.x
  • OpenCV: pip install opencv-python
  • MediaPipe: pip install mediapipe

Certifique-se de ter estes pacotes instalados antes de executar o código.

Passo 1: Criar o Ficheiro Python

Crie o ficheiro ex01_mediapipe.py e insira o código abaixo.

Passo 2: Importar Bibliotecas

import cv2
import mediapipe as mp

Passo 3: Inicializar o Objectron e a Captura de Vídeo

  • Definir a webcam padrão (índice 0).
  • Configurar o contexto do Objectron, especificando o tipo de objeto a detetar (chávena), as confianças mínimas de deteção e acompanhamento.
mp_drawing = mp.solutions.drawing_utils
mp_objectron = mp.solutions.objectron

cap = cv2.VideoCapture(0)

with mp_objectron.Objectron(
    static_image_mode=False,
    max_num_objects=5,
    min_detection_confidence=0.5,
    min_tracking_confidence=0.99,
    model_name='Cup') as objectron:

Passo 4: Ciclo de Captura e Processamento

Dentro de um ciclo infinito, iremos:

  • Ler cada fotograma da webcam.
  • Converter o espaço de cor de BGR para RGB (necessário para o MediaPipe).
  • Processar o fotograma com o Objectron.
  • Se forem detetados objetos, desenhar as landmarks 2D e o eixo 3D sobre a imagem.
  • Exibir a imagem processada (espelhada horizontalmente).
  • Permitir encerrar a execução premindo a tecla ESC.
    while cap.isOpened():
        success, image = cap.read()
        if not success:
            # Caso não seja possível ler um fotograma, continuar
            print("A ignorar fotograma vazio da câmara.")
            continue

        # Converter para RGB
        image.flags.writeable = False
        image = cv2.cvtColor(image, cv2.COLOR_BGR2RGB)

        # Processar a imagem com o Objectron
        results = objectron.process(image)

        # Preparar a imagem para desenho
        image.flags.writeable = True
        image = cv2.cvtColor(image, cv2.COLOR_RGB2BGR)

        # Desenhar landmarks e eixos 3D, se houver objetos detetados
        if results.detected_objects:
            for detected_object in results.detected_objects:
                mp_drawing.draw_landmarks(
                    image, 
                    detected_object.landmarks_2d, 
                    mp_objectron.BOX_CONNECTIONS
                )
                mp_drawing.draw_axis(
                    image, 
                    detected_object.rotation, 
                    detected_object.translation
                )

        # Exibir a imagem, espelhando-a horizontalmente
        cv2.imshow('MediaPipe Objectron - Chávena', cv2.flip(image, 1))

        # Premir ESC para sair
        if cv2.waitKey(5) & 0xFF == 27:
            break

Passo 5: Libertar a Captura e Fechar as Janelas

Após sair do ciclo, liberte a captura e feche todas as janelas:

cap.release()
cv2.destroyAllWindows()

Passo 6: Executar o Programa

No terminal, execute:

python ex01_mediapipe.py

Resultado Esperado

  • Ao iniciar o programa, a webcam será ativada.
  • Uma janela será apresentada, exibindo a imagem da webcam.
  • Se houver uma chávena no campo de visão, o MediaPipe Objectron deve detetá-la e desenhar as suas landmarks, assim como o eixo 3D que indica a orientação do objeto no espaço.
  • Prima a tecla ESC a qualquer momento para fechar a janela e encerrar o programa.

Ex 02: Deteção e Acompanhamento de Mãos em Tempo Real com MediaPipe Hands

Descrição

Neste exercício, vamos utilizar o MediaPipe Hands para detetar e acompanhar mãos em tempo real, utilizando a webcam. O MediaPipe Hands identifica um conjunto de pontos (landmarks) na mão, permitindo análise de gestos, posições e movimentos dos dedos.

Etapas principais:

  1. Capturar vídeo em tempo real a partir da webcam.
  2. Utilizar o MediaPipe Hands para detetar as mãos no quadro de vídeo.
  3. Desenhar as landmarks e as conexões dos dedos e da palma da mão sobre a imagem.
  4. Exibir o resultado numa janela, com a imagem espelhada horizontalmente.
  5. Permitir ao utilizador encerrar a execução premindo a tecla ESC.

Pré-Requisitos

  • Python 3.12.x
  • OpenCV: pip install opencv-python
  • MediaPipe: pip install mediapipe

Certifique-se de ter estes pacotes instalados antes de executar o código.

Passo 1: Criar o Ficheiro Python

Crie o ficheiro ex02_mediapipe_hands.py e insira o código abaixo.

Passo 2: Importar Bibliotecas

  • Ler cada fotograma da webcam.
  • Converter a imagem de BGR para RGB.

  • Desenhar as landmarks da mão e as suas conexões, se forem detetadas.

Ex 03: Deteção e Acompanhamento de Objetos em Vídeo com YOLOv11

Descrição

Neste exercício, vamos utilizar a biblioteca ultralytics e o modelo YOLOv11 para realizar a deteção e o acompanhamento (tracking) de objetos em tempo real. O acompanhamento permite atribuir um ID único a cada objeto, mantendo a sua identidade ao longo do vídeo.

Etapas principais:

  1. Carregar o modelo YOLOv11 nano.
  2. Configurar a captura de vídeo da webcam e o gravador de vídeo.
  3. Processar cada fotograma para detetar e acompanhar objetos (persist=True).
  4. Desenhar as caixas delimitadoras e os IDs dos objetos.
  5. Gravar e exibir o resultado.

Pré-Requisitos

  • Python 3.13.x
  • OpenCV: pip install opencv-python
  • Ultralytics: pip install ultralytics

Passo 1: Criar o Ficheiro Python

Crie o ficheiro ex03_yolo_tracking.py e insira o código abaixo.

Passo 2: Importar Bibliotecas

Importamos o OpenCV para manipulação de vídeo e a classe YOLO da biblioteca ultralytics, bem como utilitários para anotação gráfica.

import cv2
# Necessário instalar a biblioteca ultralytics, por exemplo: pip install ultralytics
from ultralytics import YOLO
from ultralytics.utils.plotting import Annotator, colors

Passo 3: Inicializar o Modelo e a Captura de Vídeo

  • Carregamos o modelo yolo11n.pt (versão nano, mais rápida).
  • Configuramos a webcam e definimos a resolução desejada.
  • Obtemos as dimensões e FPS para configurar o VideoWriter, que guardará o resultado num ficheiro .avi.
# Carregar o modelo de deteção YOLO (sem segmentação)
model = YOLO("yolo11n.pt")
# model = YOLO("best.pt")

# Captura de vídeo a partir da webcam
cap = cv2.VideoCapture(0)
cap.set(3, 1280)
cap.set(2, 720)

# Obter as dimensões e fps (frames por segundo) do vídeo de entrada
w, h, fps = (int(cap.get(x)) for x in (cv2.CAP_PROP_FRAME_WIDTH,
                                       cv2.CAP_PROP_FRAME_HEIGHT,
                                       cv2.CAP_PROP_FPS))

# Criar um escritor de vídeo para guardar o resultado do processamento
out = cv2.VideoWriter("object-detection-tracking.avi",
                      cv2.VideoWriter_fourcc(*"MJPG"), fps, (w, h))

Passo 4: Ciclo de Captura e Processamento (Tracking)

Dentro do ciclo principal:

  • Lemos o fotograma (im0).
  • Executamos model.track(persist=True), onde persist=True garante que os IDs dos objetos são mantidos entre fotogramas.
  • Se houver deteções com IDs, iteramos sobre elas para desenhar a caixa e a etiqueta (Classe + ID).
# Ciclo principal para ler e processar cada fotograma do vídeo
while True:
    ret, im0 = cap.read()
    if not ret:
        # Se não for possível ler mais fotogramas, sair do ciclo
        break

    # Inicializar o objeto 'annotator' para desenhar caixas e anotações no fotograma
    annotator = Annotator(im0, line_width=2)

    # Executar o tracking (acompanhamento) de objetos no fotograma atual
    results = model.track(im0, persist=True)

    # Se existirem deteções com IDs, desenhar as caixas delimitadoras no fotograma
    if results[0].boxes.id is not None:
        boxes = results[0].boxes.xyxy.cpu()
        track_ids = results[0].boxes.id.int().cpu().tolist()
        classes = results[0].boxes.cls.int().cpu().tolist()

        # Para cada objeto detetado, desenhar a caixa, cor e etiqueta (classe + ID)
        for box, track_id, cls in zip(boxes, track_ids, classes):
            color = colors(track_id, True)
            label = f"{model.names[cls]} {track_id}"
            annotator.box_label(box, label, color=color)

    # Escrever o fotograma anotado no vídeo de saída
    out.write(im0)
    # Mostrar o fotograma anotado numa janela
    cv2.imshow("object-detection-tracking", im0)

    # Se o utilizador carregar na tecla 'q', sair do ciclo
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

Passo 5: Libertar Recursos

Ao sair do ciclo, libertamos a câmara, o ficheiro de vídeo e fechamos as janelas.

# Libertar o escritor de vídeo e o objeto de captura de vídeo
out.release()
cap.release()
# Fechar todas as janelas abertas
cv2.destroyAllWindows()

Passo 6: Executar o Programa

No terminal, execute:

python ex03_yolo_tracking.py

Resultado Esperado

  • Uma janela abrirá mostrando a imagem da webcam.
  • Objetos detetados (pessoas, cadeiras, etc.) terão uma caixa colorida e um ID numérico.
  • Se o objeto se mover, o ID deve acompanhar o objeto.
  • Um vídeo object-detection-tracking.avi será criado.

Ex 04: Segmentação por Instâncias e Acompanhamento de Objetos em Vídeo com YOLOv11

Descrição

Neste exercício, avançamos para a Segmentação por Instâncias. Ao contrário da deteção simples (que usa caixas retangulares), a segmentação identifica o contorno exato (polígono) do objeto. Continuaremos a usar o tracking para manter a identidade dos objetos.

Etapas principais:

  1. Carregar o modelo de segmentação YOLOv11 (yolo11n-seg.pt).
  2. Capturar vídeo da webcam.
  3. Obter as máscaras (contornos) dos objetos detetados.
  4. Desenhar o polígono preenchido sobre o objeto e a respetiva etiqueta.
  5. Gravar e exibir o resultado.

Pré-Requisitos

  • Mesmos requisitos do Ex 03.
  • Necessário o modelo de segmentação (será descarregado automaticamente).

Passo 1: Criar o Ficheiro Python

Crie o ficheiro ex04_yolo_segmentation.py e insira o código abaixo.

Passo 2: Importar Bibliotecas

Adicionamos a importação do numpy para auxiliar no desenho dos polígonos.

import cv2
import numpy as np 
# Necessário instalar a biblioteca ultralytics, por exemplo: pip install ultralytics
from ultralytics import YOLO
from ultralytics.utils.plotting import Annotator, colors

Passo 3: Inicializar Modelo e Vídeo

Carregamos o modelo específico para segmentação (yolo11n-seg.pt) e configuramos a captura e gravação de vídeo.

# Carregar o modelo de segmentação YOLO
model = YOLO("yolo11n-seg.pt")
# model = YOLO("best.pt")

# Captura de vídeo a partir de um ficheiro (ou webcam id 0)
cap = cv2.VideoCapture(0)

cap.set(3, 1280)
cap.set(2, 720)

# Obter as dimensões e fps
w, h, fps = (int(cap.get(x)) for x in (cv2.CAP_PROP_FRAME_WIDTH,
                                       cv2.CAP_PROP_FRAME_HEIGHT,
                                       cv2.CAP_PROP_FPS))

# Criar um escritor de vídeo
out = cv2.VideoWriter("instance-segmentation-object-tracking.avi",
                      cv2.VideoWriter_fourcc(*"MJPG"), fps, (w, h))

Passo 4: Ciclo de Processamento e Desenho das Máscaras

Neste ciclo, verificamos se existem masks (máscaras) além dos IDs.

  • Extraímos as coordenadas dos polígonos (results[0].masks.xy).
  • Utilizamos cv2.fillPoly para pintar a máscara sobre o objeto.
  • Utilizamos annotator.box_label para colocar o ID.
while True:
    ret, im0 = cap.read()
    if not ret:
        break

    # Inicializar o annotator
    annotator = Annotator(im0, line_width=2)

    # Executar o tracking
    results = model.track(im0, persist=True)

    # Verificar se existem deteções, IDs e máscaras
    if results[0].boxes.id is not None and results[0].masks is not None:
        # Obter máscaras, IDs e também as Caixas (Boxes)
        masks = results[0].masks.xy
        track_ids = results[0].boxes.id.int().cpu().tolist()
        boxes = results[0].boxes.xyxy.cpu() # <--- Necessário para desenhar a etiqueta

        # Ciclo atualizado para incluir 'box'
        for box, mask, track_id in zip(boxes, masks, track_ids):
            color = colors(int(track_id), True)
            txt_color = annotator.get_txt_color(color)

            # 1. Desenhar a Máscara (Polígono)
            # Convertemos a máscara para int32 para o OpenCV desenhar
            cv2.fillPoly(im0, [np.array(mask, dtype=np.int32)], color)

            # 2. Desenhar a Caixa e o ID (Usando o método oficial)
            annotator.box_label(box, label=str(track_id), color=color, txt_color=txt_color)

    # Escrever o fotograma anotado no vídeo de saída
    out.write(im0)
    # Mostrar o fotograma anotado numa janela
    cv2.imshow("instance-segmentation-object-tracking", im0)

    # Se o utilizador carregar na tecla 'q', sair do ciclo
    if cv2.waitKey(1) & 0xFF == ord("q"):
        break

Passo 5: Libertar Recursos

# Libertar o escritor de vídeo e o objeto de captura de vídeo
out.release()
cap.release()
# Fechar todas as janelas abertas
cv2.destroyAllWindows()

Passo 6: Executar o Programa

No terminal, execute:

python ex04_yolo_segmentation.py

Resultado Esperado

  • A janela mostrará a webcam com os objetos cobertos por uma cor translúcida que segue a forma do objeto (segmentação).
  • Os objetos terão o seu ID visível.
  • Um vídeo instance-segmentation-object-tracking.avi será gerado.
