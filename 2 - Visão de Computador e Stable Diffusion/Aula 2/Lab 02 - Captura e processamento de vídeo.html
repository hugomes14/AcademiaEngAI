Ex 04: Deteção de Cor em Tempo Real com HSV

Descrição

Este exercício consiste em:

  1. Capturar vídeo em tempo real da webcam.
  2. Converter cada frame do espaço de cores BGR para HSV.
  3. Definir um intervalo de valores HSV correspondentes a uma cor específica (neste caso, azul).
  4. Criar uma máscara que segmenta somente as regiões da imagem que contenham a cor alvo.
  5. Aplicar uma operação bitwise-AND entre a imagem original e a máscara para obter apenas as partes azuis da cena.
  6. Exibir, lado a lado, o frame original, a máscara resultante e a imagem filtrada.
  7. Permitir que o utilizador encerre a execução pressionando a tecla ESC.

Passo 1: Criar o Arquivo Python

Crie o arquivo ex_04_Deteccao_de_Cor_HSV.py e insira o código abaixo.

### Passo 2: Importar Bibliotecas
python import cv2 import numpy as np

Passo 3: Inicializar a Captura de Vídeo

Utilize a webcam padrão do sistema (índice 0):

cap = cv2.VideoCapture(0)

Passo 4: Loop de Captura e Processamento

Dentro de um loop infinito, capture cada frame do vídeo, converta para HSV e aplique o threshold de cor.

while True:
    # Ler cada frame da webcam
    ret, frame = cap.read()
    if not ret:
        break
    
    # Converter para HSV
    hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)

    # Definir o intervalo de cor azul no espaço HSV
    lower_blue = np.array([110,50,50])
    upper_blue = np.array([130,255,255])

    # Criar a máscara
    mask = cv2.inRange(hsv, lower_blue, upper_blue)

    # Extrair apenas a parte azul da imagem
    res = cv2.bitwise_and(frame, frame, mask=mask)

    # Exibir as janelas
    cv2.imshow('Frame Original', frame)
    cv2.imshow('Mascara', mask)
    cv2.imshow('Resultado', res)

    # Pressione ESC para sair
    k = cv2.waitKey(5) & 0xFF
    if k == 27:
        break

Passo 5: Encerrar a Captura e Fechar Janelas

Após sair do loop, liberar a captura e destruir as janelas:

cap.release()
cv2.destroyAllWindows()

Passo 6: Executar o Programa

No terminal, execute:

python ex_04_Deteccao_de_Cor_HSV.py

Resultado Esperado

  • Ao iniciar o script, a webcam será ativada.
  • Três janelas serão exibidas:
    • Frame Original: Exibe a imagem capturada pela webcam sem modificações.
    • Mascara: Mostra a máscara binária destacando apenas as regiões azuis (branco onde há azul, preto onde não há).
    • Resultado: Exibe apenas a porção azul da imagem, “apagando” o resto da cena.

Passo 2: Função para Obter Temperatura da Cidade

Esta função faz uma busca no Google e extrai a temperatura atual da cidade, caso disponível.

def obter_temperatura(cidade):
    cidade_query = cidade.replace(" ", "+")
    URL = f"https://www.google.com/search?q=temperatura+em+{cidade_query}"
    headers = {
        "User-Agent": ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
                       "AppleWebKit/537.36 (KHTML, like Gecko) "
                       "Chrome/114.0.0.0 Safari/537.36")
    }

    response = requests.get(URL, headers=headers)
    soup = BeautifulSoup(response.text, "html.parser")

    try:
        temperatura = soup.find("span", class_="wob_t").text
        return temperatura
    except AttributeError:
        return None

Ex 06: Subtração de Fundo

Descrição

Este exercício consiste em:

  1. Carregar um vídeo (vtest.avi) ou a webcam.

  2. Criar um objeto de subtração de fundo (Background Subtractor) usando MOG2, por exemplo.

  3. Aplicar operações morfológicas para limpar o ruído do primeiro plano.

  4. Exibir o resultado da subtração de fundo.

  5. Medir o tempo de processamento por frame utilizando cv2.getTickCount() e cv2.getTickFrequency():

    • cv2.getTickCount() retorna o número de “ticks” desde o início da medição.
    • cv2.getTickFrequency() retorna quantos ticks ocorrem por segundo.

    Dividindo a diferença de ticks entre o início e o fim do processamento por cv2.getTickFrequency(), obtemos o tempo em segundos.

  6. Permitir encerrar o loop pressionando ESC (tecla 27).

Código

import numpy as np
import cv2

# Inicializar a captura de vídeo
cap = cv2.VideoCapture('vtest.avi')
# Se quiser usar a webcam, descomente a linha abaixo e comente a anterior
# cap = cv2.VideoCapture(0)

# Escolher método de subtração de fundo
method = 1

if method == 0:
    bgSubtractor = cv2.bgsegm.createBackgroundSubtractorMOG()
elif method == 1:
    bgSubtractor = cv2.createBackgroundSubtractorMOG2()
else:
    bgSubtractor = cv2.bgsegm.createBackgroundSubtractorGMG()

# Criar um kernel para operações morfológicas
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))

while True:
    # Ler o próximo frame do vídeo
    ret, frame = cap.read()
    if not ret:
        break

    # Início da contagem de tempo
    tick_start = cv2.getTickCount()

    # Aplicar a subtração de fundo
    foregroundMask = bgSubtractor.apply(frame)

    # Remover ruídos com operação morfológica de abertura
    foregroundMask = cv2.morphologyEx(foregroundMask, cv2.MORPH_OPEN, kernel)

    # Fim da contagem de tempo
    tick_end = cv2.getTickCount()

    # Cálculo do tempo de processamento do frame
    time_per_frame = (tick_end - tick_start) / cv2.getTickFrequency()

    # Exibir a máscara resultante
    cv2.imshow('background subtraction', foregroundMask)

    # Mostrar opcionalmente o tempo de processamento no console
    # (Caso não deseje imprimir, pode comentar a linha abaixo)
    print(f"Tempo por frame: {time_per_frame:.6f} segundos")

    # Esperar 30 ms por uma tecla; se for ESC (27), sair do loop
    k = cv2.waitKey(30) & 0xff
    if k == 27:
        break

# Liberar recursos
cap.release()
cv2.destroyAllWindows()

Execução

No terminal, digite:

python ex_06_Subtracao_de_Fundo.py

Resultado Esperado

  • Uma janela chamada “background subtraction” mostrando a máscara de primeiro plano (branco) sobre o fundo subtraído (preto).
  • No console, será exibido o tempo que cada frame levou para ser processado, em segundos.
  • Pressione a tecla ESC para encerrar o programa.

Ex 07: Rastreamento de Pontos usando Optical Flow

Descrição

Neste exercício, irá:

  1. Carregar um vídeo (vtest.avi) ou utilizar um vídeo da webcam.

  2. Detectar cantos de interesse (features) no primeiro frame usando Shi-Tomasi corner detection.

  3. Aplicar o método de Lucas-Kanade para calcular o fluxo óptico dos pontos entre frames consecutivos.

  4. Desenhar as trajetórias (tracks) dos pontos que estão se movendo.

  5. Medir o tempo de processamento por frame utilizando:

    • cv2.getTickCount() para obter o “tick” atual.
    • cv2.getTickFrequency() para saber quantos ticks há por segundo.

    Desta forma, é possível avaliar o desempenho do algoritmo quadro a quadro.

  6. Encerrar o programa ao pressionar a tecla ESC.

Passo 1: Importar Bibliotecas

import numpy as np
import cv2

Passo 2: Inicializar a Captura de Vídeo

cap = cv2.VideoCapture('vtest.avi')
# Caso deseje usar a webcam, comente a linha acima e descomente a abaixo:
# cap = cv2.VideoCapture(0)

Passo 3: Definir Parâmetros para Detecção de Cantos e Optical Flow

  • feature_params para Shi-Tomasi corner detection
  • lk_params para Lucas-Kanade optical flow
feature_params = dict( maxCorners = 100,
                       qualityLevel = 0.3,
                       minDistance = 7,
                       blockSize = 7 )

lk_params = dict( winSize  = (15,15),
                  maxLevel = 2,
                  criteria = (cv2.TERM_CRITERIA_EPS | cv2.TERM_CRITERIA_COUNT, 10, 0.03))

Passo 4: Criar Cores Aleatórias para Desenhar as Trajetórias

color = np.random.randint(0,255,(100,3))

Passo 5: Ler o Primeiro Frame e Encontrar Cantos Iniciais

ret, old_frame = cap.read()
if not ret:
    print("Não foi possível ler o primeiro frame do vídeo.")
    cap.release()
    cv2.destroyAllWindows()
    exit()

old_gray = cv2.cvtColor(old_frame, cv2.COLOR_BGR2GRAY)
p0 = cv2.goodFeaturesToTrack(old_gray, mask=None, **feature_params)

# Criar uma máscara para desenhar as trajetórias
mask = np.zeros_like(old_frame)

Passo 6: Loop de Processamento do Vídeo

Em cada iteração:

  • Ler o próximo frame.
  • Converter para tons de cinza.
  • Calcular o fluxo óptico Lucas-Kanade.
  • Selecionar apenas os pontos de boa qualidade.
  • Desenhar as linhas e círculos representando o movimento.
  • Medir o tempo de processamento por frame.
  • Mostrar o resultado.
  • Sair com ESC.
while True:
    ret, frame = cap.read()
    if not ret:
        break

    # Medir tempo início
    tick_start = cv2.getTickCount()

    frame_gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)

    # Calcular o fluxo óptico
    p1, st, err = cv2.calcOpticalFlowPyrLK(old_gray, frame_gray, p0, None, **lk_params)

    # Selecionar apenas pontos "bons"
    good_new = p1[st == 1]
    good_old = p0[st == 1]

    # Desenhar as trajetórias
    for i, (new, old) in enumerate(zip(good_new, good_old)):
        a, b = new.ravel()
        c, d = old.ravel()
        # Converter coords para inteiro
        a, b, c, d = map(int, [a, b, c, d])
        mask = cv2.line(mask, (a,b), (c,d), color[i].tolist(), 2)
        frame = cv2.circle(frame, (a,b), 5, color[i].tolist(), -1)

    img = cv2.add(frame, mask)

    # Medir tempo fim
    tick_end = cv2.getTickCount()
    time_per_frame = (tick_end - tick_start) / cv2.getTickFrequency()

    # Mostrar o tempo no console (opcional)
    print(f"Tempo por frame: {time_per_frame:.6f} segundos")

    cv2.imshow('frame', img)
    k = cv2.waitKey(30) & 0xff
    if k == 27:
        break

    # Atualizar o frame e pontos antigos
    old_gray = frame_gray.copy()
    p0 = good_new.reshape(-1, 1, 2)

Passo 7: Liberar Recursos

cv2.destroyAllWindows()
cap.release()

Resultado Esperado

  • No console, será mostrado o tempo de processamento de cada frame em segundos.
  • Pressione ESC para encerrar o programa.

Ex 08: Rastreamento de Objeto usando MeanShift

Descrição

Neste exercício, irá:

  1. Iniciar a captura de vídeo da webcam.

  2. Selecionar uma região de interesse (ROI) inicial no primeiro frame e calcular seu histograma HSV.

  3. Aplicar o algoritmo MeanShift a cada frame subsequente para determinar a nova posição do objeto rastreado.

  4. Exibir um retângulo sobre o objeto rastreado.

  5. Medir o tempo de processamento por frame:

    • cv2.getTickCount() retorna o número de ticks atuais.
    • cv2.getTickFrequency() retorna quantos ticks ocorrem por segundo.

    Dividindo a diferença de ticks pelo TickFrequency, obtemos o tempo em segundos.

  6. Encerrar o programa ao pressionar ESC.

Passo 1: Importar Bibliotecas

import numpy as np
import cv2

Passo 2: Iniciar a Captura da Webcam

cap = cv2.VideoCapture(0)

Passo 3: Ler o Primeiro Frame e Definir a ROI

  • Ler o primeiro frame da câmera.
  • Definir a janela inicial (ROI) no centro do frame.
  • Converter a ROI para HSV e criar uma máscara para ignorar áreas escuras.
  • Calcular o histograma da ROI e normalizá-lo.
ret, frame = cap.read()
if not ret:
    print("Não foi possível ler o primeiro frame da webcam.")
    cap.release()
    cv2.destroyAllWindows()
    exit()

rows, cols = frame.shape[:2]

windowWidth = 150
windowHeight = 200
windowCol = int((cols - windowWidth) / 2)
windowRow = int((rows - windowHeight) / 2)
window = (windowCol, windowRow, windowWidth, windowHeight)

roi = frame[windowRow:windowRow + windowHeight, windowCol:windowCol + windowWidth]
roiHsv = cv2.cvtColor(roi, cv2.COLOR_BGR2HSV)

lowLimit = np.array((0., 60., 32.))
highLimit = np.array((180., 255., 255.))
mask = cv2.inRange(roiHsv, lowLimit, highLimit)

roiHist = cv2.calcHist([roiHsv], [0], mask, [180], [0, 180])
cv2.normalize(roiHist, roiHist, 0, 255, cv2.NORM_MINMAX)

Passo 4: Definir Critérios de Parada do MeanShift

O MeanShift irá parar após 10 iterações ou se o objeto se mover menos que 1 pixel.

terminationCriteria = (cv2.TERM_CRITERIA_COUNT | cv2.TERM_CRITERIA_EPS , 10, 1)

Passo 5: Loop de Rastreamento

Para cada frame:

  • Ler o frame.
  • Medir o tempo de início com cv2.getTickCount().
  • Converter para HSV.
  • Calcular a projeção do histograma (backprojection).
  • Aplicar a máscara para ignorar áreas escuras.
  • Aplicar o MeanShift para obter a nova posição da janela.
  • Desenhar o retângulo da ROI.
  • Medir o tempo de fim e calcular o tempo por frame.
  • Exibir o tempo no console (opcional).
  • Mostrar o frame.
  • Pressionar ESC para encerrar.
while True:
    ret , frame = cap.read()
    if not ret:
        break

    # Início da contagem de tempo
    tick_start = cv2.getTickCount()

    frameHsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    backprojectedFrame = cv2.calcBackProject([frameHsv], [0], roiHist, [0, 180], 1)

    mask = cv2.inRange(frameHsv, lowLimit, highLimit)
    backprojectedFrame &= mask

    # Aplicar MeanShift
    ret, window = cv2.meanShift(backprojectedFrame, window, terminationCriteria)

    windowCol, windowRow = window[:2]
    frame = cv2.rectangle(frame, (windowCol, windowRow), (windowCol + windowWidth, windowRow + windowHeight), 255, 2)

    # Fim da contagem de tempo
    tick_end = cv2.getTickCount()
    time_per_frame = (tick_end - tick_start) / cv2.getTickFrequency()

    # Mostrar o tempo por frame no console (opcional)
    print(f"Tempo por frame: {time_per_frame:.6f} segundos")

    cv2.imshow('meanshift', frame)
    k = cv2.waitKey(60) & 0xff
    if k == 27:
        break

Ex 09: Rastreamento de Objeto usando CamShift

Descrição

Neste exercício, irá:

  1. Iniciar a captura de vídeo da webcam.

  2. Selecionar uma região de interesse (ROI) inicial no primeiro frame e calcular seu histograma no espaço HSV.

  3. Aplicar o algoritmo CamShift a cada frame subsequente para ajustar dinamicamente a janela de rastreamento do objeto, mesmo se seu tamanho ou orientação mudarem.

  4. Desenhar um polígono sobre o objeto rastreado.

  5. Medir o tempo de processamento por frame:

    • cv2.getTickCount() para obter o número de ticks.
    • cv2.getTickFrequency() para saber quantos ticks existem por segundo.

    Ao dividir a diferença de ticks pela frequência, obtemos o tempo em segundos por frame.

  6. Encerrar o programa ao pressionar ESC.

Passo 1: Importar Bibliotecas

import numpy as np
import cv2

Passo 2: Iniciar a Captura da Webcam

cap = cv2.VideoCapture(0)

Passo 3: Ler o Primeiro Frame e Definir a ROI

  • Ler o primeiro frame.
  • Definir a janela inicial (ROI) no centro do frame.
  • Converter a ROI para HSV.
  • Criar uma máscara para ignorar áreas escuras.
  • Calcular o histograma da ROI e normalizá-lo.
ret, frame = cap.read()
if not ret:
    print("Não foi possível ler o primeiro frame da webcam.")
    cap.release()
    cv2.destroyAllWindows()
    exit()

rows, cols = frame.shape[:2]
windowWidth = 150
windowHeight = 200
windowCol = int((cols - windowWidth) / 2)
windowRow = int((rows - windowHeight) / 2)
window = (windowCol, windowRow, windowWidth, windowHeight)

roi = frame[windowRow:windowRow + windowHeight, windowCol:windowCol + windowWidth]
roiHsv = cv2.cvtColor(roi, cv2.COLOR_BGR2HSV)

lowLimit = np.array((0., 60., 32.))
highLimit = np.array((180., 255., 255.))
mask = cv2.inRange(roiHsv, lowLimit, highLimit)

roiHist = cv2.calcHist([roiHsv], [0], mask, [180], [0, 180])
cv2.normalize(roiHist, roiHist, 0, 255, cv2.NORM_MINMAX)

Passo 4: Definir Critérios de Parada do CamShift

terminationCriteria = (cv2.TERM_CRITERIA_COUNT | cv2.TERM_CRITERIA_EPS , 10, 1)

Passo 5: Loop de Rastreamento com CamShift

Para cada frame:

  • Ler o frame.
  • Medir o tempo de início com cv2.getTickCount().
  • Converter o frame para HSV.
  • Calcular a backprojection a partir do histograma.
  • Aplicar a máscara para ignorar áreas escuras.
  • Aplicar o CamShift para obter o novo retângulo rotacionado envolvendo o objeto.
  • Desenhar o polígono da região rastreada.
  • Medir o tempo de fim e calcular o tempo por frame.
  • Opcionalmente imprimir o tempo de processamento no console.
  • Exibir o frame.
  • Pressionar ESC para sair.
while True:
    ret, frame = cap.read()
    if not ret:
        break

    # Início da contagem de tempo
    tick_start = cv2.getTickCount()

    frameHsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
    backprojectedFrame = cv2.calcBackProject([frameHsv], [0], roiHist, [0, 180], 1)
    mask = cv2.inRange(frameHsv, lowLimit, highLimit)
    backprojectedFrame &= mask

    # Aplicar CamShift
    ret, window = cv2.CamShift(backprojectedFrame, window, terminationCriteria)

    # Desenhar o polígono resultante do CamShift
    points = cv2.boxPoints(ret)
    points = np.int0(points)
    frame = cv2.polylines(frame, [points], True, 255, 2)

    # Fim da contagem de tempo
    tick_end = cv2.getTickCount()
    time_per_frame = (tick_end - tick_start) / cv2.getTickFrequency()

    # Imprimir tempo por frame (opcional)
    print(f"Tempo por frame: {time_per_frame:.6f} segundos")

    cv2.imshow('camshift', frame)
    k = cv2.waitKey(60) & 0xff
    if k == 27:
        break

cv2.destroyAllWindows()

Resultado Esperado

  • No console, será mostrado o tempo de processamento a cada frame.
  • Pressione ESC para encerrar o programa.

Este exercício demonstra a utilização do algoritmo CamShift para rastreamento de objetos com tamanho e orientação variáveis, bem como a medição do tempo de processamento por frame para avaliar o desempenho da solução.

Ex 10: Deteção de Rostos e Olhos com Haar Cascades

Descrição

Neste exercício, irá:

  1. Carregar classificadores Haar Cascade para detecção de rostos e olhos.

  2. Iniciar a captura de vídeo da webcam.

  3. Para cada frame:

    • Converter para escala de cinza.
    • Detectar rostos.
    • Para cada rosto, detectar olhos (no máximo dois).
    • Desenhar retângulos ao redor do rosto e dos olhos.

  4. Medir o tempo de processamento por frame:

    • cv2.getTickCount() fornece o número de ticks atuais.
    • cv2.getTickFrequency() informa quantos ticks por segundo existem.

    Dividindo a diferença entre ticks do início e do fim pelo TickFrequency, obtemos o tempo em segundos por frame.

  5. Exibir o tempo de processamento no console (opcional).

  6. Encerrar o programa pressionando a tecla ‘q’.

Passo 1: Importar Bibliotecas

import numpy as np
import cv2

Passo 2: Carregar os Classificadores Haar Cascade

Certifique-se de ter os arquivos de cascata (haarcascade_frontalface_default.xml e haarcascade_eye.xml) no diretório especificado.

faceCascade = cv2.CascadeClassifier('haarcascades/haarcascade_frontalface_default.xml')
eyeCascade = cv2.CascadeClassifier('haarcascades/haarcascade_eye.xml')

Passo 3: Iniciar a Captura de Vídeo da Webcam

cap = cv2.VideoCapture(0)

Passo 4: Loop de Detecção

Para cada frame capturado:

  • Medir o tempo inicial (tick_start).
  • Converter o frame para tons de cinza.
  • Detectar rostos com faceCascade.detectMultiScale().
  • Para cada rosto detectado, desenhar retângulo e detectar olhos.
  • Desenhar retângulos para os olhos detectados (no máximo 2).
  • Medir o tempo final (tick_end), calcular o tempo por frame e opcionalmente exibir no console.
  • Mostrar o frame com as detecções.
  • Pressionar ‘q’ para encerrar.
while True:
    ret, frame = cap.read()
    if not ret:
        break
    
    # Início da contagem de tempo
    tick_start = cv2.getTickCount()
    
    # Converter para escala de cinza
    gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
    
    # Detectar rostos
    faces = faceCascade.detectMultiScale(gray, scaleFactor=1.3, minNeighbors=5)
    
    for x, y, w, h in faces:
        # Desenhar retângulo do rosto
        cv2.rectangle(frame, (x, y), (x + w, y + h), (255, 0, 0), 2)
        
        # ROI para olhos
        roiGray = gray[y:y+h, x:x+w]
        eyes = eyeCascade.detectMultiScale(roiGray)
        
        eyeCounter = 0
        for ex, ey, ew, eh in eyes:
            if eyeCounter > 1:
                break
            # Desenhar retângulo nos olhos
            cv2.rectangle(frame, (ex + x, ey + y), (ex + x + ew, ey + y + eh), (0, 255, 0), 2)
            eyeCounter += 1
    
    # Fim da contagem de tempo
    tick_end = cv2.getTickCount()
    time_per_frame = (tick_end - tick_start) / cv2.getTickFrequency()
    
    # Imprimir tempo por frame (opcional)
    print(f"Tempo por frame: {time_per_frame:.6f} segundos")

    cv2.imshow('frame', frame)
    k = cv2.waitKey(20) & 0xFF
    if k == ord('q'):
        break

Passo 5: Liberar Recursos

cap.release()
cv2.destroyAllWindows()

Execução

No terminal, execute:

python ex_10_FaceEyeDetection_Haar.py

Resultado Esperado

  • Uma janela chamada “frame” exibindo o vídeo da webcam.
  • Detecções de rostos em retângulos azuis.
  • Detecções de olhos em retângulos verdes (no máximo dois por rosto).
  • No console, o tempo de processamento de cada frame em segundos.
  • Pressione ‘q’ para encerrar o programa.

Este exercício demonstra como combinar a detecção de faces e olhos com Haar Cascades e ao mesmo tempo avaliar o desempenho do algoritmo através da medição do tempo por frame.
