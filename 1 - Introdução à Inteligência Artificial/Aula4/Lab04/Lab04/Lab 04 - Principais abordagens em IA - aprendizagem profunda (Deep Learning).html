Ex 1: Ensinar o Drone ‘Coruja’ a ser um Especialista em Moda

Objetivo: O teu objetivo é configurar o “cérebro” de um drone de reconhecimento de imagem chamado ‘Coruja’. A Coruja precisa de aprender a identificar diferentes tipos de artigos de moda a partir de imagens. Vais usar o PyTorch para carregar um dataset de imagens de moda, construir uma rede neuronal, treiná-la e, finalmente, testar os conhecimentos de moda da Coruja.

Instruções: Segue cada passo, lê o enunciado para perceber o que o código faz e executa os blocos de código em sequência num ambiente com Python e PyTorch instalados. Depois, responde às questões no final.

Passo 1: Importar as Ferramentas Necessárias

Enunciado: Para começar, precisamos de importar todas as bibliotecas e módulos do PyTorch que nos vão permitir trabalhar com dados (DataLoader, datasets), construir a rede neuronal (nn) e transformar as nossas imagens em tensores, o formato de dados que o PyTorch utiliza (ToTensor).

import torch
from torch import nn
from torch.utils.data import DataLoader
from torchvision import datasets
from torchvision.transforms import ToTensor

Passo 2: Obter os “Catálogos de Moda” (Datasets)

Enunciado: A Coruja precisa de material de estudo. Vamos usar o datasets.FashionMNIST da torchvision, que contém milhares de imagens de artigos de moda. Descarregamos dois conjuntos: um para treinar a Coruja (train=True) e outro para testar o que ela aprendeu no final (train=False). O transform=ToTensor() converte automaticamente as imagens para o formato que a nossa rede neuronal consegue entender.

# Descarregar dados de treino de datasets públicos.
dados_treino = datasets.FashionMNIST(
    root="data",
    train=True,
    download=True,
    transform=ToTensor(),
)

# Descarregar dados de teste de datasets públicos.
dados_teste = datasets.FashionMNIST(
    root="data",
    train=False,
    download=True,
    transform=ToTensor(),
)

Passo 3: Organizar os Dados em Lotes (Batches)

Enunciado: Não mostramos todas as imagens à Coruja de uma só vez; isso seria ineficiente. Em vez disso, usamos o DataLoader para agrupar as imagens em lotes (neste caso, de 64). O DataLoader irá entregar estes lotes à Coruja um de cada vez durante o treino. Vamos também inspecionar o formato (shape) de um lote de imagens (X) e das suas etiquetas (y) para percebermos como os dados estão estruturados.

batch_size = 64

# Criar os carregadores de dados.
train_dataloader = DataLoader(dados_treino, batch_size=batch_size)
test_dataloader = DataLoader(dados_teste, batch_size=batch_size)

# Vamos espreitar um lote para ver o formato dos dados.
for X, y in test_dataloader:
    print(f"Formato do lote de imagens X [N, C, A, L]: {X.shape}")
    print(f"Formato do lote de etiquetas y: {y.shape} {y.dtype}")
    break

Passo 4: Desenhar o Cérebro da Coruja (O Modelo)

Enunciado: Aqui, desenhamos a arquitetura da nossa rede neuronal. Criamos uma classe CerebroCoruja que herda de nn.Module, a classe base para todos os modelos de redes neuronais em PyTorch. A nossa arquitetura é simples:

  1. nn.Flatten(): Transforma a imagem 2D (28x28 pixels) num vetor 1D.
  2. nn.Sequential: Uma sequência de camadas lineares (nn.Linear) com funções de ativação ReLU entre elas. Estas camadas são responsáveis por encontrar padrões nas imagens. A última camada tem 10 saídas, uma para cada categoria de roupa.
class CerebroCoruja(nn.Module):
    def __init__(self):
        super().__init__()
        self.flatten = nn.Flatten()
        self.linear_relu_stack = nn.Sequential(
            nn.Linear(28*28, 512),
            nn.ReLU(),
            nn.Linear(512, 512),
            nn.ReLU(),
            nn.Linear(512, 10)
        )

    def forward(self, x):
        x = self.flatten(x)
        logits = self.linear_relu_stack(x)
        return logits

Passo 5: Construir o Cérebro e Escolher o Local de Treino

Enunciado: Primeiro, verificamos se existe uma GPU (cuda) disponível, pois é muito mais rápida para treinar redes neuronais. Se não houver, usamos a CPU. Depois, criamos uma instância do CerebroCoruja e movemo-la para o dispositivo escolhido (device) usando .to(device).

device = "cuda" if torch.cuda.is_available() else "cpu"
print(f"A usar o dispositivo: {device}")

modelo = CerebroCoruja().to(device)
print(modelo)

Passo 6: Definir as Ferramentas de Aprendizagem

Enunciado: Para a Coruja aprender, precisamos de duas ferramentas:

  1. Função de Perda (loss_fn): nn.CrossEntropyLoss calcula o quão erradas estão as previsões da Coruja em comparação com as etiquetas reais.
  2. Otimizador (optimizer): torch.optim.SGD (Stochastic Gradient Descent) é o algoritmo que ajusta os parâmetros internos do modelo para tentar minimizar o erro calculado pela função de perda.
loss_fn = nn.CrossEntropyLoss()
optimizer = torch.optim.SGD(modelo.parameters(), lr=1e-3)

Passo 7: Criar a Rotina de Treino

Enunciado: Esta função treinar define uma “sessão de estudo” completa. Para cada lote de imagens no dataloader, ela faz uma previsão, calcula o erro (loss) e, mais importante, realiza a retropropagação (loss.backward()) e atualiza os pesos do modelo (optimizer.step()). É neste processo que a aprendizagem efetivamente acontece. optimizer.zero_grad() reinicia os gradientes para que não se acumulem entre lotes.

def treinar(dataloader, model, loss_fn, optimizer):
    size = len(dataloader.dataset)
    model.train() # Coloca o modelo em modo de treino
    for batch, (X, y) in enumerate(dataloader):
        X, y = X.to(device), y.to(device)

        # Calcular o erro da previsão
        pred = model(X)
        loss = loss_fn(pred, y)

        # Retropropagação (Backpropagation)
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        if batch % 100 == 0:
            loss, current = loss.item(), (batch + 1) * len(X)
            print(f"perda: {loss:>7f}  [{current:>5d}/{size:>5d}]")

Passo 8: Criar a Rotina de Teste

Enunciado: Após cada sessão de estudo, testamos a Coruja. A função testar avalia o desempenho do modelo no conjunto de dados de teste. Ela calcula a exatidão (Accuracy) e a perda média. É crucial usar with torch.no_grad() para garantir que não são feitos ajustes ao modelo durante o teste. model.eval() informa ao PyTorch que o modelo está em modo de avaliação.

def testar(dataloader, model, loss_fn):
    size = len(dataloader.dataset)
    num_batches = len(dataloader)
    model.eval() # Coloca o modelo em modo de avaliação
    test_loss, correct = 0, 0
    with torch.no_grad():
        for X, y in dataloader:
            X, y = X.to(device), y.to(device)
            pred = model(X)
            test_loss += loss_fn(pred, y).item()
            correct += (pred.argmax(1) == y).type(torch.float).sum().item()
    test_loss /= num_batches
    correct /= size
    print(f"Erro no Teste: \n Exactidão: {(100*correct):>0.1f}%, Perda Média: {test_loss:>8f} \n")

Passo 9: Começar o Treino!

Enunciado: Agora, juntamos tudo. Definimos o número de epochs (ciclos completos de treino sobre todo o dataset). Dentro do ciclo for, chamamos a função treinar e, em seguida, a função testar para cada época, permitindo-nos observar a Coruja a ficar progressivamente mais inteligente.

epochs = 5
for t in range(epochs):
    print(f"Época {t+1}\n-------------------------------")
    treinar(train_dataloader, modelo, loss_fn, optimizer)
    testar(test_dataloader, modelo, loss_fn)
print("Treino concluído!")

Passo 10: Guardar as “Memórias” da Coruja

Enunciado: Após um treino intensivo, não queremos que a Coruja perca o seu conhecimento. Guardamos o estado do modelo (model.state_dict()), que contém todos os parâmetros aprendidos, num ficheiro chamado coruja_fashion.pth.

torch.save(modelo.state_dict(), "coruja_fashion.pth")
print("As memórias da Coruja foram guardadas em coruja_fashion.pth")

Passo 11: Carregar as Memórias e Fazer uma Previsão

Enunciado: Para terminar, simulamos o reinício da Coruja. Criamos uma nova instância do modelo, carregamos os pesos guardados com load_state_dict e pedimos-lhe para identificar um artigo de moda do conjunto de teste. Definimos uma lista de classes para traduzir a previsão numérica do modelo (de 0 a 9) para um nome de artigo legível.

modelo = CerebroCoruja().to(device)
modelo.load_state_dict(torch.load("coruja_fashion.pth"))

classes = [
    "T-shirt/top", "Calças", "Camisola", "Vestido", "Casaco",
    "Sandália", "Camisa", "Sapatilha", "Mala", "Bota",
]

modelo.eval()
x, y = dados_teste[0][0], dados_teste[0][1]
with torch.no_grad():
    x = x.to(device)
    pred = modelo(x)
    previsto, real = classes[pred[0].argmax(0)], classes[y]
    print(f'A Coruja previu: "{previsto}", O artigo real era: "{real}"')
