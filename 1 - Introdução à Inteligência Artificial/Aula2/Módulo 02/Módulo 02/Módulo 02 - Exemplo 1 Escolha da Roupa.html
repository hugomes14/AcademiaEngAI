Exemplo 1: Escolha da Roupa

  • Problema: Que roupa vestir dependendo da temperatura?
  • Símbolos:
    • ( T1 ): Temperatura está abaixo de 15°C.
    • ( T2 ): Temperatura está entre 15°C e 25°C.
    • ( T3 ): Temperatura está acima de 25°C.
    • ( R1 ): Vestir um casaco.
    • ( R2 ): Vestir uma camisola.
    • ( R3 ): Vestir uma t-shirt.
  • Regras:
    • Se ( T1 ) é verdadeiro, então ( R1 ) (vestir um casaco).
    • Se ( T2 ) é verdadeiro, então ( R2 ) (vestir uma camisola).
    • Se ( T3 ) é verdadeiro, então ( R3 ) (vestir uma t-shirt).
  • Exemplo de Decisão:
    • Temperatura: 10°C
    • Ação: O sistema decide que deves vestir um casaco porque a temperatura está abaixo de 15°C.
