Exemplo 5: Manutenção do Carro

  • Problema: Quando fazer a manutenção do carro?
  • Símbolos:
    • ( M1 ): O carro fez mais de 10.000 km desde a última manutenção.
    • ( M2 ): O carro fez menos de 10.000 km.
    • ( S1 ): Agendar uma manutenção.
    • ( S2 ): Não é necessário agendar manutenção.
  • Regras:
    • Se ( M1 ) é verdadeiro, então ( S1 ) (agendar uma manutenção).
    • Se ( M2 ) é verdadeiro, então ( S2 ) (não é necessário agendar manutenção).
  • Exemplo de Decisão:
    • Quilometragem: O carro fez 12.000 km.
    • Ação: O sistema decide que deves agendar uma manutenção.
