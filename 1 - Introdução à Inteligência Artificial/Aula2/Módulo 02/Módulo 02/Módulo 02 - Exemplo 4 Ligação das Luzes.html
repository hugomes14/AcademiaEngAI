Exemplo 4: Ligação das Luzes

  • Problema: Quando ligar as luzes em casa?
  • Símbolos:
    • ( N1 ): Está de noite.
    • ( D1 ): Está de dia.
    • ( L1 ): Ligar as luzes.
    • ( L2 ): Manter as luzes apagadas.
  • Regras:
    • Se ( N1 ) é verdadeiro, então ( L1 ) (ligar as luzes).
    • Se ( D1 ) é verdadeiro, então ( L2 ) (manter as luzes apagadas).
  • Exemplo de Decisão:
    • Hora do dia: Está de noite.
    • Ação: O sistema decide que deves ligar as luzes.
