Exemplo 2: Planear a Refeição

  • Problema: O que comer ao pequeno-almoço?
  • Símbolos:
    • ( F1 ): Está com pressa.
    • ( F2 ): Tem tempo disponível.
    • ( C1 ): Comer uma barra de cereais.
    • ( C2 ): Comer uma refeição completa (ovos, torradas, etc.).
  • Regras:
    • Se ( F1 ) é verdadeiro, então ( C1 ) (comer uma barra de cereais).
    • Se ( F2 ) é verdadeiro, então ( C2 ) (comer uma refeição completa).
  • Exemplo de Decisão:
    • Situação: Tem tempo disponível.
    • Ação: O sistema decide que deves comer uma refeição completa.
